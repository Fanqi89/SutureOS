## 一句话

`logo/` 存放 **SutureOS 的系统 Logo**：一枚「多块拼图咬合成完整系统」的原创标识。
本目录里的 10 张 PNG **是同一张画面的 10 种像素尺寸**，不是 10 个不同图标；
`SutureOS_logo_1536.png` 是母版，也就是开机 / 关机动画用的那张图。

## 目录事实（必须按这个认知工作）

- 本文件加入后，目录共 **12 项**：11 项素材 + `README.md`（本文件）。
- **全部平铺**，无子文件夹、无 `menu/`、无 `boot/`、无单独的「开机图标」目录。
- **目录内没有 ZIP**，不需要解压、不要去找 `SutureOS_logo_开始菜单图标_多尺寸.zip`。
- **没有中文别名文件**，`SutureOS_logo_开关机动画.png` 不存在；母版唯一文件名就是 `SutureOS_logo_1536.png`。
- 没有第二张开关机图：开机与关机共用 1536，只是动画正放与倒放。

## 每个文件是什么

| 文件 | 是什么 | 用在哪 |
|---|---|---|
| `SutureOS_logo_{16,24,32,48,64,128,256,512,1024}.png` | 母版经 Lanczos 重采样的小尺寸副本 | 按控件尺寸取：任务栏 16/24、开始菜单按钮 32/48、磁贴 64/128、大图 256/512、过渡 1024 |
| `SutureOS_logo_1536.png` | 1536×1536 RGB 源图，**唯一母版** | 开机/关机全屏动画、关于页大图 |
| `MANIFEST.txt` | 纯文本，写明 `16→24→32→48→64→128→256→512→1024→1536` 顺序 | 只供核对顺序，**不是第 11 张图片，不要转成位图** |
| `README.md` | 本说明 | 只读，不编进 ISO |

规格序列固定为：`16 → 24 → 32 → 48 → 64 → 128 → 256 → 512 → 1024 → 1536`。
前 6 档是非幂间隔，之后翻倍。不可乱序、不可跳档改名。

## 它画的是什么（语义，别改）

- 多块**非等分拼图**带半圆咬合口，严丝合缝拼成一枚完整闭合徽记 → 多个上游模块拼成完整系统
- 加宽的块间暗缝 → 一眼看得出是「一块一块拼起来的」
- 右上角琥珀色那块更亮 → 过程叙事：「最后刚拼上的一块」，对应系统持续集成新模块
- 中心发光方点 → 宏内核，所有模块汇入的落点
- 全图**不含文字**；系统名由 banner / 任务栏文本给出
- 全部 RGB、**无 alpha 通道**；小尺寸下细缝变细是像素限制，不是设计差异

这是**原创视觉资产**，不是从任何上游操作系统移植来的模块。

## 你要拿它做什么

1. 在 `scripts/` 写转换脚本，把 PNG 编成内核可加载的 **C 位图常量**（注意帧缓冲像素格式与 RGB 顺序），产物放 `kernel/gui/`，随构建进 ISO。
2. **内核运行时不读 PNG**；`logo/` 只放素材，不放生成的 `.h`。
3. 开始菜单 / 任务栏**直接按尺寸从本目录平铺的 10 档取**，不硬编码某一档、不另做「开始菜单专属图标」。
4. 开关机动画**只用 `SutureOS_logo_1536.png`**，不需要分帧素材：按 9 个预定义矩形区域依次 clip 绘制 → 逐块咬合显现 → 右上琥珀块最后落位 → 中心内核点转亮 → 收成静态 Logo。开机约 1.2–1.6 s；关机逆序、快一倍（0.6–0.8 s），**不等待动画结束**。
5. 挂接后更新 `gui_appearance_check.py` 像素基线，在 `CHANGELOG.md` 登记。
6. 终端左栏那枚**字符画 Logo 是独立资产，不在本目录**，不要从 PNG 去「识别」或 OCR 生成。

## 绝对不能做（违反即停止并报告）

- 重新生成、重画、简化、锐化、改色、抠图、二次重采样、补透明通道。
- 看到「开始菜单」字样就另出一版小尺寸简图；或把 1536 再缩一份当「开机图」。
- 把 `MANIFEST.txt` 当图片处理，或把 `README.md` 编进 ISO。
- 把 Logo 写进 `THIRD_PARTY_LICENSES.md` 或 `docs/provenance.md`——那两份**只记上游移植来源**；本资产登记在 `CHANGELOG.md` 即可。
- 把 1536 编进 ISO 两次，或假设还有中文别名文件、ZIP、子目录、6 档以外的隐藏档位。
- 改动 10 档中任何一档的拼图块数、咬合口、右上琥珀块、中心内核点。
- 若 `B24「GUI 重做」` 未收口：图标会改像素基线，**先报告冲突再动手**，不要擅自覆盖。
- 未经确认提交、打 tag、发 Release、向工作区外写文件。

## 遇到不确定怎么办

找不到文件、哈希对不上、尺寸对不上、看不清缩略图——一律写 `UNVERIFIED` 并说明缺什么证据。
**不猜路径、不补全文件、不凑结论、不把 README 自述或文件名当运行证据。**

## 其他
