## 🚀 本次更新 (v0.49.0 → v0.50.0)

**拖动顺了 4–5 倍（≈117 ms → 60–80 ms/帧）**：图层合成器第一刀落地——拖动窗口时**不再重新栅格化磨砂体**，
而是复用拖动开始时抓下的窗口层；任务栏整条缓存成一层；拖动期间只把「旧/新窗口矩形」呈现到 framebuffer；
每帧校验和从全屏 786k 像素改成每 8 像素采样。外壳验收扩到 **40/40**。

---

### 🧱 图层合成器（第一刀，v0.50.0）

| 项 | 做法 |
|---|---|
| 拖动复用窗口层 | 拖动中几何每帧变，但**内容不变**：直接 blit 拖动开始时缓存的层（含阴影）；拖动结束时把 `WIN_KEY[drag]` 置 `i32::MIN`，下一次重绘在终点重新栅格化 |
| 任务栏层缓存 | 整条任务栏（磨砂带 + 按钮 + 时钟 + 用户/FPS）缓存到 `1024×38` 缓冲；键 = 时钟 + 焦点 + 悬停按钮 + 四窗口 open/minimized/z。命中则 blit |
| 部分呈现 | 拖动帧只 `blit_rect` 旧矩形 + 新矩形（其余像素屏上已正确），不再整屏拷贝 |
| 采样校验和 | 每帧对全屏 786k 像素做 FNV 原本要 ~20–30 ms；改为每 8 像素采样 |
| 日志 | `[gui-shell] drag: reusing window layer (no re-rasterise)`、`[gui-shell] drag repaint N ticks (copy/win/bar)` |

### ⚠️ 已知限制（如实记录）

1. 拖动中的窗口**磨砂底纹停留在拖动起点时的样子**（合成器语义：内容不重绘），松手后一次重绘才对上新位置；这是真合成器的正常行为，但肉眼在长距离拖动时会察觉。
2. 仍是 ring-0 单线程软件合成，没有 vsync/双缓冲交换链；拖动 ~60–80 ms 仍明显滞后于手。
3. 任务栏缓存键未包含窗口标题（标题目前静态）；一旦标题可变必须同步扩键。
4. 最大化/还原、开始菜单仍无过渡动画；时区写死 +08:00；键盘只在菜单内。
5. Wayland 前置（AF_UNIX/SCM_RIGHTS/poll/memfd）与「用新外壳替换 C 桌面」尚未开始。
