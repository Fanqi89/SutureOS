### ⚠️ 已知限制（如实记录）

1. 模糊是**整块静态一次性**计算（单帧），60 fps 动态背景还没做——真实界面里背景一动就要重算这块区域。
2. 半径固定 18/14 px，没有按"浮层层级"分级；没有亚克力噪点/颗粒（Win11 亚克力有细微 noise）。
3. 模糊矩形如果用满 1024 宽 × 480 高会到 1.9 MiB .bss；当前调用远小于上限，但上限是硬编码。
4. 仍是静态样板帧：无输入/动效/窗口管理；文字仍只有 GB2312 子集。
