### ⚠️ 已知限制（如实记录）

1. 最大化/还原的"淡入"是**整块叠暗再变亮**，不是真的缩放动画（放大过程没有中间尺寸）。
2. 开始菜单淡入同样只是叠暗；菜单项没有逐行/滑动动画。
3. 拖动落点仍会**重新栅格化一次**（~40 ms），这是一次性开销，不是每帧。
4. 层仍是不透明层：重叠窗口的阴影带内显示"变暗的壁纸"。
5. 仍是 ring-0 单线程软合成，无 vsync/交换链；时区写死 +08:00；键盘只在开始菜单内。
6. **Wayland 前置（AF_UNIX/SCM_RIGHTS/poll/memfd）与「用新外壳替换 C 桌面」尚未开始。**
