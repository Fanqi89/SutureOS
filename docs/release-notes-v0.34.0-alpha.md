## 🚀 本次更新 (v0.33.0 → v0.34.0)

**桌面外壳第一批**：①**应用注册表**——所有软件登记在一张表里，开始菜单**运行时从注册表生成**，
新增软件只加一行就自动出现在菜单里；②**固定任务栏**——默认软件（任务管理器/计算器/图片查看器/
文本编辑器）固定在任务栏左侧，点击即启动或置顶；③**窗口最小化/最大化真正可用**——最小化到任务栏，
**点同一个任务栏按钮在"还原 ↔ 最小化"之间切换**，最大化按钮/双击标题栏真正改窗口几何，
新增键盘快捷键 `m`（最大化/还原）、`n`（最小化）。

### 📦 应用注册表（开始菜单的唯一来源）

`kernel/gui/apps.c` 新增 `g_app_registry[]`：

| 字段 | 作用 |
|---|---|
| `app_id` | 交给 `gui_apps_launch()` 创建窗口（`APP_ID_*`） |
| `label` | 开始菜单/任务栏按钮显示的名字 |
| `pinned` | 1 = 永久固定在任务栏左侧 |

`kernel/gui/gui.c` 的 `gui_start_menu_build()` 在 GUI 启动时把它展开成菜单项（后面自动补分隔线 +
"Exit to terminal"），菜单高度/命中检测都按运行时项数算，所以**加一个应用只需在注册表加一行**。
启动日志会打印 `[gui] start menu: 8 items from app registry`，可断言。

### 📌 固定任务栏 + 🗔 最小化/最大化

- 任务栏左侧顺序：开始按钮 → **固定应用按钮（最多 4 个）** → 运行窗口按钮（最多 6 个）→ 右侧时钟/用户/FPS。
- 固定按钮：显示的 App 窗口活跃时高亮；点击 → `gui_activate_app()`（没开就启动、最小化/关闭就恢复、已开就置顶）。
- 窗口按钮：**点击切换**——窗口是活跃态就最小化（并把焦点交给下一个可见窗口），否则还原并置顶。
- 最大化/还原：`gui_flip_window()` 原来只重绘（是个空壳），现在真的保存 `norm_x/y/w/h` → 全屏（1024×728，减去任务栏）
  → 再点恢复原几何；标题栏最大化按钮、双击标题栏、快捷键 `m` 三条入口共用它。
- 快捷键：`m` 最大化/还原焦点窗口、`n` 最小化焦点窗口（与既有 q/r 一样，文本框有焦点时不抢键）。

### ⚠️ 已知限制（如实记录）

1. 固定按钮最多 4 个、窗口按钮最多 6 个（超出不画按钮，但 Tab 仍可切）；按钮标题截断到 10/14 字符。
2. 任务栏没有右键菜单、不能把运行中的窗口"固定/取消固定"（固定关系来自注册表编译期）。
3. 最大化是几何变化，不保证每个 app 的自绘内容都适配 1024×728（Task Manager/About 会画满，编辑器按客户区重画）。
4. 双击标题栏判定窗口 400ms，双击后仍会触发一次拖拽起始（松手即可，不影响结果）。
5. 开始菜单最多容纳 18 个应用（`START_MAX_ITEMS`），超过会截断；没有分页/滚动。
6. GUI 大改（风格方向）按用户要求暂缓，本批只动功能。
