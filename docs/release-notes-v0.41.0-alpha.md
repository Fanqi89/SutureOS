### ⚠️ 已知限制（如实记录）

1. 帧率约 2 fps（TCG 下）：窗口内容每帧重画（磨砂 + 文本），**拖动有明显跟手延迟**；真机/带 KVM 会快很多，但没有做脏矩形。
2. 窗口内容全是占位文案；开始菜单项不可点、不启动应用；没有关闭按钮的确认、没有窗口缩放。
3. 最大化只有"填满任务栏以上"，没有动画；最小化没有过渡动画。
4. 双击判定放宽到 1500 ms（帧率低，400 ms 会被相邻帧吃掉）——真实交互里偏宽松。
5. 鼠标光标仍由 Rust 自己画（不接管 C 桌面指针），退出后回到终端。
6. 仍是 prototype：不与 C 桌面共享状态，`startgui` 的桌面完全没变。
