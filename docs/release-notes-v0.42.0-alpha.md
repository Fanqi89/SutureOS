### ⚠️ 已知限制（如实记录）

1. 帧率仍约 2 fps：交互时每帧仍整屏重绘（只有**空闲**会跳帧），拖动跟手延迟明显；脏矩形还没做。
2. 菜单项只按窗口索引启动；"图片查看器/文本编辑器"窗口内容是占位文案（没有真图片/编辑器）。
3. 关闭没有确认对话框；关闭后窗口仍保留在任务栏之外（不可再打开，除菜单重启）。
4. 最大化/最小化/启动都没有过渡动画。
5. 双击判定 1500 ms（帧率妥协）；不与 C 桌面共享状态。
