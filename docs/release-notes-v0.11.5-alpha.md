## 🚀 本次更新 (v0.11.4 → v0.11.5)

**GUI 窗口现在真的能拖动、缩放、关闭了**（界面外观保持不变）。

### 🔧 三个根因（上一批手势代码写错，不是没写）

| 现象 | 根因 | 修法 |
|---|---|---|
| 一拖就"甩飞" | 抓取偏移取自**排队的点击坐标**，而鼠标处理先刷新实时指针再排空点击队列，同帧位移不在点击记录里 | 以**实时指针**为基准并钳进屏幕 |
| 右键也触发拖动/关闭 | gui_click_at() 忽略 button，PS/2 bit1 被当左键 | 只认左键，记录右键状态 |
| 指针回跳一帧 | gui_pointer_moved() 把指针倒回点击记录位置 | 删除回跳 |
