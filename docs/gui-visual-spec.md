# SutureOS 桌面外壳视觉规范（v0.60 打磨目标）

用户 2026-11-03 定的方向：**统一圆角 + 轻亚克力（只用于背景与浮层）+ 微透叠层 + Win11 Fluent 为底 +
拟物化伪 3D 应用图标 + 轻微空间感（3D 只做空间感，不喧宾夺主）**。
v0.59 已把"有"做出来（圆角/亚克力/伪 3D 图标/淡入淡出），本文件是**继续打磨**时的量化口径：
所有改法都要按这里的 token 走，避免"这里圆一点、那里亮一点"式的随机漂移。

## 1. 设计 token

| 类别 | token | 值 | 说明 |
|---|---|---|---|
| 窗口圆角 | `R_WIN` | 12 px | 现有 `CORNER_COV` 表按 r=12 预计算，**不要再引入 f32 sqrt** |
| 行/按钮圆角 | `R_ROW` | 8 px | 设置行、菜单行、任务栏按钮 |
| 图标圆角 | `R_ICON` | 3 px（22 px 图标）/ 2 px（14 px 标题栏图标） | 用逐行 inset，见 `draw_app_icon` |
| 阴影 | `SHADOW_RING` | 8 环，α = 0x22…0x02 | 每环 4 个 rect_fill，只画周长 |
| 窗口体 | `BODY_ALPHA` | 0x2a 白色叠层 + 采样预模糊壁纸 | 提高可读性只能微调 ±0x04 |
| 标题条 | `TITLE_ALPHA` | 0x14 白 + 1 px accent(Q=0x2a) 下边线 | |
| 发丝边框 | `HAIRLINE` | 白 α=0x30 | 上下左右各 1 px，避开圆角区（±8 px） |
| 任务栏 | `TB_ALPHA` | 0x30 磨砂 + 0x08 白 | 顶部 1 px 高光 + 底部 1 px 暗边 |
| 浮层（开始菜单） | `MENU_ALPHA` | 0x34 磨砂 + 4 层阴影 | 打开 2 帧淡入（0x50→0x24） |
| 强调色 | `APP_ACCENTS` | `0x4f8dff` / `0x22c1a8` / `0xf5a524` / `0xe05a8a` | 蓝色留给新窗口 `0x7a5cff` |
| 文本 | `TEXT_HI/MID/LOW` | `0xecf2ff` / `0xc2d4ec` / `0x93a7c1` | GUI 用 `apps.rs` 里同一套 |

## 2. 本轮要落地的打磨点（按性价比排序）

1. **壁纸纵深**：在现有两块色斑之外，加一层极暗的边缘压角（vignette）与一条极淡的水平光带；
   壁纸同时是亚克力的采样源（`SMALL`），所以改一处两处都变。**保持暗部均值**（外观门禁与
   "最小化后该区域变暗"的断言都依赖背景足够暗）。
2. **窗口 chrome**：
   - 标题条左端加 accent 2×14 px 竖条（Fluent 的"应用身份"提示），标题文字保持 8×16；
   - 三个窗口控制按钮改成 18×18 圆角(4)块 + hover 时亮一档（hover 状态由 `hover_code` 伸入，
     注意**不要**让窗口层缓存带上 hover：hover 属于动态层）；
   - 主体加 1 px 顶部内高光 + 1 px 底部内暗边（"玻璃厚度"）。
3. **伪 3D 图标**：现有渐变盘 + 顶部高光已到位；补 1 px 内描边（亮 20%）与右下角反光，
   让图标在浅色/深色底上都"站得住"。图标尺寸不变（22 px 菜单 / 14 px 标题栏 / 48 px 商标）。
4. **任务栏**：窗口按钮圆角(8)、活跃项下划线改成 3 px 圆角条、hover 抬一档亮度；
   开始按钮保持 24 px Logo 平铺（**Logo 资产与 alpha 混合不要动**）。
5. **开始菜单**：行圆角(8)、行高 38 不变、选中/悬停 accent 竖条保留；底部加一行提示
   （`↑↓ 选择 ・ Enter 打开`，`TEXT_LOW` 0xd0）。
6. **过渡**：现有"打开/最大化/还原/关闭/最小化/菜单"六种都只是整块叠暗；本轮**不重做**动画
   （保持确定性，避免破坏 `intro fade`/`anim` 断言），只允许把菜单淡入从 2 帧拉长到 3 帧
   —— 前提是现有 `menu fade` 断言允许 3 行。

## 3. 硬约束

- 内核 `-mno-sse`：**逐像素禁止 f32**（软浮点一次调用数十 µs）。圆角/阴影/渐变只能用整数与查表
  （参考 `CORNER_COV`、`XMAP/YMAP`、`ROW_INSET`）。
- 光标美术**不变**（用户明确要求）。
- 启动呈现（终端 → banner → prompt）**不变**。
- 任何视觉改动都要：
  1. 重新生成 `docs/baseline/base_gui.png`（`py -3 scripts/gui_baseline_shot.py --save-baseline`），
     并在 CHANGELOG/README 里写明"外观基线本轮重生"；
  2. `py -3 scripts/gui_appearance_check.py build/acc_desktop1.ppm --profile new` 0 像素越界；
  3. 重跑 `scripts/gui_sweep.py`，逐条修因亮度阈值变化而失败的断言（**改断言要说明理由**，
     不允许把"画面上根本看不到"的东西断言通过）。
- 像素阈值型断言（`mean_brightness(...) > 90/80/70/55`、`< 90`、`|Δ| < 4`）在打磨后必须
  逐条复核：只允许调整**由打磨本身引起**的数值，不允许放宽到失去判据意义。
